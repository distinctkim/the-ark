Enter Your GitHub Token

You need a GitHub Personal Access Token with repo scope to save changes.
How do I get one?

How to create a GitHub Personal Access Token:
  1. Go to github.com/settings/tokens/new
  2. Give it a name, e.g. the-ark-admin
  3. Set an expiration (e.g. 90 days)
  4. Under Scopes, tick repo (full control of private repositories)
  5. Click Generate token and copy it
  6. Paste it in the box below — you will not see it again

⚠️ Store your token securely (e.g. in a password manager). If you lose it, generate a new one.

Your token is cleared from this page when you close the tab or log out.
